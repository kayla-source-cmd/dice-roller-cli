# Dice Roller CLI

A simple Python command-line application that simulates rolling a six-sided dice.

## Features
- Generates random numbers between 1 and 6.
- Allows users to roll multiple times.
- Accepts yes/no responses.
- Handles invalid user input.
- Allows users to quit the game.

## Technologies
- Python 3
- Random module
- While loops
- Conditional statements

## How to Run

```bash
python3 dice_roller.py
```
